01
THE MECHANIC

# wrap()

  1. caller holds 1,000,000 $WBULL
  2. tokens lock in vault PDA
  3. fresh NFT minted to caller
  4. tier index assigned (1..1000)

# unwrap()

  1. caller holds the NFT
  2. NFT burned
  3. 1,000,000 $WBULL released
  4. tier index returned to pool
vault.authority = PDA(["vault", nft_mint])  →  the locked tokens follow the NFT through every marketplace transfer. buyer of the NFT controls the vault, automatically.
