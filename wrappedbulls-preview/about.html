About

A wrapping primitive built on Solana, dressed as a memecoin.

# what it is

WrappedBulls is a Solana program plus a 1,000 piece pixel art NFT collection. The program lets anyone wrap 1,000,000 $WBULL tokens into a unique Bull NFT, and unwrap it back any time. The vault holding those tokens is owned by the NFT, so when the NFT trades, the tokens travel with it.

# in three numbers

  token          $WBULL  (Token2022, 6 decimals, fixed supply)
  max bulls      1,000  (hard cap, onchain enforced)
  tokens per nft 1,000,000 $WBULL  (vault locked while wrapped)
